## 📋 Archivos

### `catalog.example.csv`
Catálogo de ejemplo de aplicaciones y dominios de negocio.

**Columnas:**
- `application_name`: Nombre de la aplicación
- `database_name`: Base de datos
- `business_domain`: Dominio (ventas, inventario, etc.)
- `description`: Descripción

**Tu catálogo real:**
```bash
cp data/catalog.example.csv data/catalog.csv
# Editar con tus datos
```

**Nota**: `catalog.csv` está en `.gitignore`
