# 📝 Resumen de .cursorignore

## Archivos Bloqueados (círculo gris en Cursor)
- `.env` - Config real
- `.config/credentials.json` - Credenciales reales
- `data/*.csv` - Datos reales
- `*.log` - Logs
- `__pycache__/` - Python cache
- `venv/` - Virtual environment

## Archivos Permitidos (sin círculo gris)
- ✅ `.env.template` - Template de config
- ✅ `.env.example` - Ejemplo de config
- ✅ `.config/README.md` - Instrucciones
- ✅ `.config/credentials.example.json` - Template de credenciales
- ✅ `data/README.md` - Instrucciones de datos
- ✅ `data/catalog.example.csv` - Catálogo ejemplo

## Recargar Cursor
Después de modificar `.cursorignore`:
1. Cmd+Shift+P (Mac) o Ctrl+Shift+P (Windows/Linux)
2. Escribir "Reload Window"
3. Enter

Los cambios se aplicarán y los archivos example deberían aparecer sin círculo gris.
